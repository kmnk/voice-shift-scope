The first public development version, for trying out. It may change.

## What it does

- Changes the pitch (−24 to +24 semitones) and the formants (×0.5 to ×2.0) of the microphone voice separately and sends it to the chosen playback device. Lowering the pitch uses TD-PSOLA and everything else uses Signalsmith Stretch, and the output level is matched to the input
- Shows F0, F1–F4, and the harmonics of the original and shifted voice at the same time, in side-by-side spectrograms, an overlaid spectrum, and a values table
- Holds the display for both sides, only the original, or only the shifted voice, and saves the held screen as a PNG
- Restores the chosen devices, the view, the pitch and formant values, and so on at the next start

## Requirements

Windows 10 or 11 x64, and Microsoft Edge WebView2 Runtime (included in Windows 11). To pass the shifted voice to another app as a microphone, install a virtual audio device such as VB-CABLE separately.

## Files

- `voice-shift-scope-0.1.0-windows-x64.zip`: the app. Unpack it and start `voice-shift-scope.exe`
- `voice-cli-0.1.0-windows-x64.zip`: a tool for checks during development (command line)
- `SHA256SUMS.txt`: SHA-256 of the two zips

## No code signature, and the warnings

This version is not code-signed. A warning may appear when downloading in a browser, and if "Windows protected your PC" appears when starting, press "More info" and then "Run anyway". On PCs with Windows 11 Smart App Control turned on, it cannot start. See "Warnings when downloading and starting" in the README for details.
