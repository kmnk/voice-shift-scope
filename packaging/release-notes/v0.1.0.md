最初に公開する開発版。試しに使ってもらうためのもので、これから変わることがある。

## できること

- マイクの声のピッチ（−24〜+24 半音）とフォルマント（0.5〜2.0 倍）を別々に変えて、選んだ再生の機器に流す。ピッチを下げるときは TD-PSOLA、それ以外は Signalsmith Stretch で変え、出力の音量を入力にそろえる
- 変える前と後の F0・F1〜F4・倍音を、左右に並べたスペクトログラム、重ねたスペクトル、数値の表で同時に表示する
- 表示を全体、変える前だけ、変えた後だけで止め、止めた画面を PNG に保存する
- 選んだ機器、表示、ピッチとフォルマントの値などを、次の起動のときに戻す

## 動く環境

Windows 10・11 の x64 と、Microsoft Edge WebView2 Runtime（Windows 11 には含まれる）。変えた声を他のアプリにマイクとして渡すときは、VB-CABLE などの仮想の音声機器を別に入れる。

## 配布物

- `voice-shift-scope-0.1.0-windows-x64.zip`: アプリ。展開して `voice-shift-scope.exe` を起動する
- `voice-cli-0.1.0-windows-x64.zip`: 開発で確かめるための道具（コマンドライン）
- `SHA256SUMS.txt`: 2 つの zip の SHA-256

## 署名が無いことと、出る警告

この版にはコードの署名が無い。ブラウザーで落とすときに警告が出ることがあり、起動するときに「Windows によって PC が保護されました」と出たら、「詳細情報」から「実行」で起動する。Windows 11 の Smart App Control が有効な PC では起動できない。詳しくは README の「落とすときと起動するときに出る警告」にある。
