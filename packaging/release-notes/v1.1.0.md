Adds a lock that stops every control but itself.

## Changes since 1.0.1

- A lock button at the start of the top bar. While locked, every other button, field, slider, select, and keyboard shortcut does nothing, and the controls are dimmed. The plots keep updating, and pressing the lock button again releases it. The app always starts unlocked
- Updated the ringbuf dependency to 0.5

## Requirements

Windows 10 or 11 x64, and Microsoft Edge WebView2 Runtime (included in Windows 11). To pass the shifted voice to another app as a microphone, install a virtual audio device such as VB-CABLE separately.

## Files

- `voice-shift-scope-1.1.0-windows-x64.zip`: the app. Unpack it and start `voice-shift-scope.exe`
- `voice-cli-1.1.0-windows-x64.zip`: a tool for checks during development (command line)
- `SHA256SUMS.txt`: SHA-256 of the two zips

## No code signature, and the warnings

This version is not code-signed. A warning may appear when downloading in a browser, and if "Windows protected your PC" appears when starting, press "More info" and then "Run anyway". On PCs with Windows 11 Smart App Control turned on, it may not start. See "Warnings when downloading and starting" in the README for details.
